## 🌎 About The Project

**World Time Explorer** is a Python-based desktop application built with **Tkinter** that allows users to search and explore the current time of different countries around the world.

The application combines real-time timezone calculations with an interactive graphical interface featuring an animated analog clock, digital clock, country flags, date information, day/night detection, stars, sun/moon animations, and a dynamic space-inspired background.

The goal of this project is to create a visually engaging and practical world clock application while demonstrating Python GUI development, timezone handling, animations, and modular project organization.

---

## ✨ Features

### 🌍 World Time

- View the current time for different countries.
- Uses accurate IANA timezone information.
- Automatically updates the clock in real time.
- Supports different countries and time zones.

### 🔎 Country Search

- Search countries using the search box.
- Displays matching countries dynamically.
- Shows country flags in search results.
- Press `Enter` to select the first matching country.
- Clear the search with the `✕` button.

### 🕐 Digital Clock

- Displays the current time in `HH:MM:SS` format.
- Updates automatically every second.
- Uses the selected country's local timezone.

### ⏱️ Animated Analog Clock

- Fully custom-drawn analog clock using Tkinter Canvas.
- Hour, minute, and second hands.
- Smooth second-hand movement.
- Hour and minute markers.
- Animated clock rings.
- Day/night visual indicators.

Displays:

- Day
- Month
- Year
- Full formatted date
